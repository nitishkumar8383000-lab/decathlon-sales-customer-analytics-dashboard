# Decathlon Sales & Customer Analytics Dashboard

## 📊 Project Overview

This project is an interactive **Sales & Customer Analytics Dashboard built in Microsoft Excel** using Decathlon-style sports retail data.

The dashboard transforms raw sales data into meaningful business insights and provides a clear view of sales performance, customer behavior, product categories, and monthly trends.

## 🎯 Project Objectives

* Analyze overall sales performance
* Identify top-performing sports categories
* Understand customer purchasing behavior
* Track monthly sales trends
* Analyze product category contribution
* Measure customer retention
* Compare sales by gender
* Analyze payment method performance

## 📌 Key KPIs

* **Total Sales:** ₹36.7 Cr
* **Total Orders:** 30,000
* **Total Customers:** 8,998
* **Average Order Value:** ₹12,236

## 📈 Dashboard Features

* KPI Cards
* Monthly Sales Analysis
* Sales by Product Category
* Top 5 Sports Categories
* Customer Retention Analysis
* Gender-wise Sales
* Payment Method Analysis
* Year & Payment Method Filters
* Interactive Excel Slicers
* Dynamic Charts
* Professional Dashboard UI

## 🛠️ Tools & Skills Used

* Microsoft Excel
* Pivot Tables

## 🔍 Key Insights

The dashboard helps identify high-performing sports categories, understand product-category sales contribution, monitor monthly performance, and analyze customer retention.

It provides decision-makers with a quick and visual way to understand business performance and identify potential areas for growth.

5. Analyze the interactive charts and KPIs.
